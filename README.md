## Run locally
Open `index.html` in a browser, or use the Live Server extension in Visual Studio Code.

## Publish with GitHub Pages
1. Create a GitHub repository for this project.
2. Upload all project files and folders, preserving the folder structure.
3. Open the repository's **Settings**.
4. Select **Pages**.
5. Under the build and deployment section, choose **Deploy from a branch**.
6. Select the `main` branch and `/ (root)` folder, then save.
7. Wait for GitHub Pages to publish and copy the live website URL.
